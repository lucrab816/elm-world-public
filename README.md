# 埃尔的小世界 · Elm World

Godot 4 制作的生活模拟原型：埃尔在小院与树林里种植、阅读、创作、收发信件，与邻居米娅和兔子德雷克共同生活。

这是用于公开展示的源码版本，不是正式发行的游戏安装包。

## 内容

- 小院、树林、昼夜天气、种植、家具互动和建造模式。
- 生活需求、阅读、相册、绘画、日记与书籍创作。
- 模型决策桥接与本地行为逻辑；不附带登录凭据或模型额度。

## 开发入口

Godot 工程位于 `project/project.godot`。本地打包入口为 `build_app.py`，需要 Godot 与 macOS 编译工具。已在 macOS Apple Silicon 上完成原生组件编译及无界面启动检查；已从生成的独立应用完成启动退出和图形界面截图验证；尚未在全新机器验证。具体步骤见 [开发说明](DEVELOPMENT.md)。

公开副本使用独立名称 `Elm World Public Preview` 和数据目录 `ElmWorldPublicPreview`，与正式游戏分开。不要将正式存档复制到公开目录。打包脚本默认不配置模型 CLI；模型连接需要另行主动配置，不会自动复用本机登录。

## 隐私与内容边界

本公开版不包含真实存档、私人信件、日记、记忆、照片、登录配置或商业书籍正文。代码中的测试样例不代表埃尔的真实生活记录。自备本地书籍和个人数据不得提交至公开仓库。
